# AIGF local MR companion

Open `Assets/Scenes/CompanionDemo.unity` in Unity `6000.3.23f1` and press Play. The Editor scene uses a local mock planner and supports Russian/English text commands for come, sit, stand, follow, stop, wave, and look-at-user.
